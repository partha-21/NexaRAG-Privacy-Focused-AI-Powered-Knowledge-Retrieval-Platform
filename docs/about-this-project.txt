Offline Document Assistant is a Java portfolio project built with Spring Boot and LangChain4j.
It lets you upload documents and ask questions about them without using any cloud service.
Embeddings are computed inside the JVM with the all-MiniLM-L6-v2 ONNX model.
Answers are generated by a local language model served by Ollama.
The index is saved to the data folder and reloaded when the application restarts.
A folder watcher re-indexes automatically when files are added, changed or removed.
Every answer includes citations showing the source file, an excerpt and a similarity score.
